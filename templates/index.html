How the Algorithms Work

Matrix Decompositions & Transforms

Image compression relies on mathematical transformations to represent visual data more efficiently. By breaking down the image matrix into simpler components and keeping only the most significant ones, we can drastically reduce file sizes while preserving visual quality. Here are the four algorithms used:

1

SVD (Randomized)

Singular Value Decomposition factors an image matrix into three matrices, isolating the dominant "singular values". Our Randomized SVD replaces the slow exact SVD with a random sketch that finds the top-k singular vectors much faster.

A ≈ Uk · Σk · Vkᵀ

By dropping the smaller singular values, we compress the image with minimal perceptual loss.

2

PCA (Principal Components)

Principal Component Analysis identifies the directions (components) of maximum variance in the image data. It centers the data by subtracting the mean and computes the covariance matrix.

C = Xᵀ · X / (n - 1)

By keeping only the top principal components, PCA reduces dimensionality while retaining the core structures of the image.

3

NMF (Non-negative Matrix Factorization)

Unlike SVD or PCA, NMF strictly enforces non-negativity. It factors the image into two matrices, W and H, which only contain positive values.

V ≈ W · H (W, H ≥ 0)

This creates a "parts-based" representation, meaning the image is built by strictly adding components together, often preserving distinct edges and features nicely.

4

DCT (Discrete Cosine Transform)

The foundation of JPEG compression, DCT converts the image from the spatial domain into the frequency domain. It expresses data in terms of oscillating cosine functions.

Xk = Σ xn cos[π/N (n+0.5) k]

Most of the visual information concentrates in a few low-frequency coefficients. By discarding the high-frequency details, we achieve very high compression ratios.

5

Evaluate

Quality is measured across all algorithms via multiple complementary metrics:

  • PSNR — peak signal-to-noise ratio; >30 dB is good, >40 dB is excellent
  • SSIM — structural similarity; closer to 1.0 = less perceptible difference
  • MSE — mean squared error; lower = less pixel-level deviation
  • CR — compression ratio; higher = more space saved
